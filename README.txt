Judul Projek : NFNAA Personal Portfolio Website

1. Deskripsi General Web:
ini merupakan website portfolio personal dengan gaya retro yang dikembangkan menggunakan HTML murni, CSS, dan JavaScript. 
Website ini mengintegrasikan pustaka GSAP (GreenSock) untuk mengoptimalkan performa manipulasi DOM pada efek animasi teks acak (scramble text) dan kursor magnetik. 
Website ini berfungsi sebagai showcase untuk memamerkan proyek-proyek Hardware dan Software serta pencapaian di bidang tersebut.
